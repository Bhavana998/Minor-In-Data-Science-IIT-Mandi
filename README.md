Reinforcement Learning–Driven Patch Attention for Urban Scene Segmentation
🧠 Project Description
This project lies at the intersection of Reinforcement Learning (RL) and Computer Vision.
The goal is to improve urban scene segmentation by using an RL agent to learn patch-level attention, allowing the model to focus on high-impact regions in an image.
By optimizing attention policies, the approach improves segmentation performance while reducing unnecessary computation.
🚀 Key Features
RL-guided patch attention mechanism
Improved segmentation accuracy (IoU improvement observed)
Efficient focus on important image regions
Combination of CNNs with Reinforcement Learning
🛠️ Technologies Used
Programming Language: Python
Deep Learning: PyTorch
Reinforcement Learning: RL-based policy learning
Libraries: NumPy, Matplotlib
Domain: Computer Vision, Urban Scene Segmentation
